# Fire Test Method Tree

Interactive guide to which fire resistance test standard applies to which building element (BS EN, BS 476, GB, ISO 834, ASTM/UL), with classification standards and report wording.

Prepared by Hong Kong Curtain Wall Testing Centre Ltd — www.curtainwalltest.com

- Single static page: `index.html` (no build step).
- Deployed on Netlify; `netlify.toml` publishes the repo root.

Guidance only. Confirm the applicable standard and edition with the approving authority before specifying a test.
